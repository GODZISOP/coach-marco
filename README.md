A bespoke, high-performance web experience engineered for **Coach Marco** — dedicated 1-on-1 athletic coaching, periodized strength programming, biomechanical technique refinement, and customized nutrition protocols.

Built with an Awwwards-inspired brutalist aesthetic, Webflow-style masked line typography reveals, smooth Lenis scrolling, GSAP scroll scrubbing, and Framer Motion spring physics.

---

## ⚡ Key Highlights & Features

- **Webflow-Style Masked Reveals**: Typography cleanly slides up from `overflow: hidden` containers, reacting seamlessly as you scroll down and back up.
- **Electric Volt Accent Palette (`#c6f939`)**: High-contrast, razor-sharp styling on deep obsidian backgrounds.
- **Kinetic Profile & Bauhaus Grid**: Interactive athlete metrics, scroll-scrubbed typography timeline, and expandable athlete dossier.
- **Signature Skiper34 Sticky Card Stack**: Multi-layer sticky cards with smooth transforms and counter-rotating visual physics.
- **Interactive Orbit & Showcase**: 3D tilt tracking, spring squash/elastic neon capsule ("Just train."), and floating member avatars.
- **Transparent Packages & Pricing**: Annual & monthly membership options with 3D perspective stagger entrance.
- **Fast Performance & Responsive**: Eagerly loaded WebP assets, zero layout shifts, and 100% responsive down to small mobile viewports.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm, pnpm, or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/GODZISOP/coach-marco.git

# Navigate to project directory
cd coach-marco

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Next.js development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm run start
```
